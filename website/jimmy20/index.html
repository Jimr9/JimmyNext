Jimmy Next

A free Windows program that makes FT8 and FT4 operating fully accessible with a screen reader — keyboard-driven from install to QSO, with a built-in FT8/FT4 engine based on Nexus.

Jimmy Next is public beta software. It's the actively-developed next generation of Jimmy, replacing the old external-WSJT-X-companion design with a fully self-contained program. Expect occasional rough edges, and please report anything that looks wrong — see Troubleshooting for how. If you'd rather stay on the established, stable release, see production Jimmy instead; the two install and update completely independently of one another.

Download Jimmy Next

Free installer for 64-bit Windows 10/11, downloaded as a zip. Your browser or Windows may report that Jimmy Next is not commonly downloaded, because it's a small independent project — that's expected. Only continue past that warning if you downloaded it from this official Jimmy Next website or the official Jimr9/JimmyNext GitHub release; if the source or filename looks different, cancel the installation. Extract JimmyNext.msi from the zip and run it. (Prefer the installer directly? Download JimmyNext.msi — may trigger a stronger warning than the zip.) See Get Started for what to expect during setup. If Jimmy Next is already installed and running, close it before running the installer.

Want to verify the download itself? Each release on GitHub publishes the exact SHA-256 checksum for both files in its release notes — compare it against what you downloaded with certutil -hashfile JimmyNext.msi SHA256 (Windows' own built-in tool, no install needed) if you want to double-check.

What's different in Jimmy Next

Jimmy Next carries forward the same accessible, keyboard-driven operating experience as production Jimmy, on a rebuilt foundation:

  • No external WSJT-X install required. Jimmy Next bundles a built-in FT8/FT4 engine based on the free, open-source Nexus project (see Credits) — install Jimmy Next and it's ready to operate on its own.
  • One installer, self-contained. No separate .NET runtime or modified WSJT-X build to track down or keep in sync.
  • Its own separate identity from production Jimmy. Its own install, its own settings and data, and its own update channel — kept separate by design so installing or updating one is not expected to affect the other.

What Jimmy Next does

Jimmy Next builds a list of stations calling you, manages the back-and-forth of each contact, logs completed QSOs automatically, and tracks your progress toward awards like Worked All States and DXCC — all readable and controllable with JAWS or NVDA, no mouse required.

Built for screen readers

Jimmy Next is designed for keyboard and screen-reader operation throughout its primary setup and operating workflows, with clear accessible names on controls and speech output kept short and to the point.

Smart calling queue

Jimmy Next automatically lists stations calling you and prioritizes them — stations calling you directly always come first.

Award tracking

Worked All States, DXCC, and dozens more, with live alerts the moment a station you still need is heard.

Automatic logging & sync

Completed QSOs are logged for you automatically. Optional account setup enables real-time upload and syncing with QRZ, Club Log, LoTW, and eQSL — see Awards & Logging for how each service's upload and download behavior differs.

Callsign lookups

Combines QRZ, Club Log, LoTW, HamQTH, and FCC data automatically, so you know who you're working.

Fully customizable

Remap every keyboard shortcut, choose a color theme, and control exactly which sounds and messages you get.

Credits

Jimmy Next's bundled FT8/FT4 engine isn't something we built from scratch — it's based on Nexus, a free, open-source amateur radio project by KD9TAW. Nexus's own FT8/FT4 code is in turn derived from WSJT-X's GPL-licensed work by Joe Taylor, K1JT, and the WSJT Development Group. We're grateful to both projects for the work that makes Jimmy Next's engine possible.

Jimmy Next is an independent project and is not affiliated with or endorsed by the WSJT Development Group.

Jimmy itself has a separate history worth knowing: it began as Tilly, created by Andy WM8Q, and that's where the accessible, keyboard-driven approach to FT8/FT4 operating carried forward into Jimmy — and now into Jimmy Next — first came from. Tilly is part of Jimmy's own story, not part of the engine Jimmy Next bundles today.

Jimmy Next is developed by KB0UZT.
