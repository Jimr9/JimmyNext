Settings

Everything below lives in Options (Alt+O), organized into tabs.

Accessibility

Accessibility isn't a separate mode in Jimmy Next — it's how the whole program is built. Jimmy Next is designed for keyboard and screen-reader operation (JAWS and NVDA) throughout its primary setup and operating workflows, with plain-language accessible names on controls. A few settings specifically control how much Jimmy Next says:

  • Keep list position during refresh (Advanced UI tab) — uncheck this for quieter screen-reader behavior when lists update frequently.
  • Move focus to status after selecting a call (General tab, off by default) — re-announces the status line right after you pick a call from a list.
  • A dedicated Accessibility Navigation group of hotkeys jumps focus directly to any list or status area — see Keyboard Commands.
  • Nearly every hotkey in Jimmy Next, including navigation shortcuts, can be reassigned to a key combination that works for you. A small handful of fixed commands (Delete, Escape, and Ctrl+Y) aren't reassignable — see Keyboard Commands for the full list.

Radio

The Radio tab is where you point Jimmy Next at your rig for CAT control and PTT/audio — select your radio and audio devices there. Since the bundled engine (based on Nexus — see Credits) handles this directly, there's no separate program's radio settings to keep in sync.

Split Operation — None, Rig, or Fake It — also lives here, and works exactly as it does in WSJT-X: it controls how a transmit offset is realized on your radio (true CAT split, or a dial-shift emulation), independent of where in the passband you actually operate. That "where" is on the Transmit tab, below.

Explain meter readings (Alt+Q) — off by default. The Alt+Q quick check normally speaks bare numbers (for example "power 45 watts, SWR 1.4, ALC 0.30" while transmitting, or "Audio in 31 dB" while receiving). Turn this on to add a short plain-language hint to each reading — "SWR 1.4, good", "ALC 0.30, a little high, reduce audio", "Audio in 31 dB, good" — and, while receiving, your radio's S-meter in S-units ("S-meter S7") when the rig reports it over CAT. The S-meter is never spoken while transmitting, because a radio can't measure an incoming signal with the transmitter keyed.

Radio input/output master level (%) (Decode Engine tab) — sets the Windows system volume for whichever audio devices you've selected for your radio, separate from the engine's own FT8/FT4 transmit tone (drive) level. Saved per profile and reapplied automatically at startup, when the engine restarts, or if you change audio devices.

Transmit

The Transmit tab holds how Jimmy Next replies and where it transmits:

  • Transmit frequency — Best free frequency (automatic) (the default; Jimmy Next finds a clear gap in the passband for each CQ and reply), Hold Tx frequency (keep your current transmit frequency, follow the worked station on receive only — WSJT-X's "Hold Tx Freq" on), or Transmit on station's frequency (move both transmit and receive onto the station you answer — classic double-click-to-work). Jimmy Next never changes your transmit frequency in the middle of a contact. See Using Jimmy Next for how each mode behaves, plus the keyboard commands for setting frequency by hand.
  • Frequency step (Hz) — how far the transmit and receive frequency nudge keys (Shift+F11/F12 and Ctrl+Shift+F11/F12) move per press. Default 60 Hz; set it smaller for fine work, larger to clear a pile-up quickly.
  • Repeat limit — how many times the same message is repeated to a station that isn't answering before Jimmy Next gives up and moves to the next call. This is now the single control for that; the old "Extended Timeout" / "Hold" toggle has been removed.
  • Smart Mode — when on, Enter on a station means "work it when the moment is right" rather than "call it now": Jimmy Next watches that station and calls, waits, yields, and hands off on its own. Only with Smart Mode on does Jimmy Next stop calling a station that is busy working someone else (after Other-station replies before yielding); with it off, it keeps calling until the repeat limit. Start after target not heard for (1–10 receive periods) sets how long a quiet gap counts as the station being free. Two more settings bound how long Jimmy Next keeps trying before giving up: Give up after this many consecutive calls with no target heard (1–20, default 4) stops it once that many calling attempts in a row pass with no sign of the target at all — hearing it for any reason, even working another station, resets the count back to zero — and Overall time limit in minutes (0 by default, meaning no limit) is an absolute cap on the whole effort regardless of how many calls happened — set it if you want to know for certain that Jimmy Next will stop trying a station after, say, an hour. See Using Jimmy Next.
  • Optimize throughput, Log early, Use RR73, Skip my grid, and the transmit-period default also live here.

Appearance

The Appearance tab controls how the station lists look, for sighted users or anyone using screen magnification:

  • Theme — Default, Dark, or High Contrast presets.
  • Independent color pickers for list background, list text, and alternating-row color, if you want something other than a preset.
  • Per-alert colors — give any alert category (New DXCC, Zone Needed, Always Wanted, and the rest) its own foreground and background color, independent of the general list colors, so the calling queue can visually stand out row by row.
  • List font size — 8 to 18 points.
  • A Restore Defaults button to reset colors and font size back to Jimmy Next's original look.

Separately, the row order editor (Alt+I) chooses which fields each station row shows and in what order — callsign, reply status, alert tag, grid, signal report, audio frequency (the hertz the station is transmitting on), country/state, distance and direction, and more — independently for the Stations calling list, the raw decodes list, and the Spot Watch list. Audio frequency is off by default; add it here to see it.

Internet time check

Internet time check (General tab, off by default) has Nexus measure your PC clock against time servers and correct transmit and decode timing by it. Changing it takes effect right away, without restarting the engine, and switching between profiles with different settings no longer restarts it either.

Profiles and shared settings

Each profile keeps its own radio, audio and operating settings. Your callsign and grid, operator name and contest email, TQSL station location, and your QRZ, LoTW, Club Log, HRDLog, eQSL and HamQTH logins are shared by every profile, so a new profile starts with them and a change reaches every profile. Next to each of these is a This profile only checkbox: check it to give the current profile its own value (a portable grid, a second TQSL location) without touching the others; uncheck it to go back to the shared value. The first start of this version moves your existing profiles over automatically and backs them up first; a profile that already had different values keeps them as "this profile only". Save current configuration first (Options, Profiles) now stays the way you set it.

Sounds

Jimmy Next can play a distinct sound for 16 different events — a new call added, a call directed to you, a QSO logged, transmit enabled, a new DXCC (overall or on the current band), a new grid square (overall or on the current band), an always-wanted call, a directed CQ, POTA or SOTA activity, a wanted call heard anywhere, an interesting call on the opposite period, and a needed-award match. Each one can be turned on or off individually and pointed at your own .wav file, with a Test button to preview it. A new grid counts only the grid the station actually sent, never a lookup's home grid. One new DXCC / new grid sound per receive period (off by default) plays each of those four sounds at most once per receive period, however many stations it found — the spoken summary still gives the counts.

Alert regions (Sounds tab, Choose regions) keeps the new DXCC, new grid, directed CQ, POTA, SOTA and call-added sounds to the continents and countries you chase. It starts as All regions, which changes nothing. A station calling you, an always-wanted call and a wanted call heard anywhere always sound; award alerts, Still Need, the station lists, ranking and automatic calling are never affected. A station whose location isn't known yet still sounds.

Changing the spoken wording

Notifications and speech

Separate from the alert sounds above, the Notifications tab controls what Jimmy Next says — both its routine operating status (receive and transmit state, the receive-cycle summary, "QSO started", "QSO logged", the transmit message) and its event announcements (radio CAT link lost or recovered, computer clock out of sync, an automatic transmit resume, Station Watch and Smart Mode activity, and more). For each one you can:

  • Turn it on or off.
  • Reword it — every announcement is a plain-text template with {Field} placeholders (callsign, band, mode, and so on) you can edit.
  • Choose when it's spoken — right away, after the current receive period, after the current transmission, or after the whole QSO ends — so it never talks over something you're waiting to hear.
  • Choose whether it's spoken during an active QSO, only outside a QSO, always, or never (shown on screen and in history only).
  • Set a minimum gap before the same announcement can repeat.

A Global speech behaviour group sets the default timing and during-a-QSO rule for the whole routine status line at once, so you can dial in how talkative Jimmy Next is overall and then override individual events as needed. Safety-critical notices — the radio CAT link dropping, for example — are always spoken immediately regardless of these settings. Ctrl+Shift+H opens a Notification History window listing everything Jimmy Next has presented this session, whether or not it was spoken aloud.

Lookups

Jimmy Next can combine several sources into one record for any callsign — country, DXCC entity, state, grid, LoTW status, and more. All of it is optional and configured on the Lookup Data tab in Options:

  • QRZ Callsign Lookup — your normal QRZ.com login (username and password). Adds name, country, state, grid, and QSL manager info, cached locally. A free login works, but QRZ restricts the data fields it returns without an XML Data subscription; adding that subscription's API key (see below) unlocks full data.
  • Club Log Country Data — an offline country/DXCC reference dataset Jimmy Next downloads and refreshes automatically, no account needed.
  • HamQTH — an alternate callsign lookup source, cached the same way as QRZ.
  • LoTW User Activity — tracks which callsigns are known LoTW users, usable as an optional tiebreaker when ranking the calling queue.
  • FCC ULS — the official FCC amateur license database, for the most authoritative US state on a callsign, and downloaded weekly rather than fetched per-call. Opt-in and off by default, since it's roughly a 170 MB download; it always takes priority over QRZ's state guess once enabled. It can also fill in an operator's name for US callsigns — QRZ's own profile name is still preferred, but some QRZ profiles only have a first name/initial on file with no last name, so Jimmy Next uses whichever source's name is more complete.

A master Use lookup data switch turns all of this off at once without losing your saved settings. Looking up a station manually (the Lookup Selected Station command, unassigned by default, works from any list — see Keyboard Commands) shows whatever's already known immediately, and automatically checks QRZ live if that callsign hasn't been looked up yet.

Your own logbook's upload/download credentials — QRZ Logbook, Club Log, LoTW, and eQSL — live on a separate Logbook Sync tab instead, since they serve a different purpose (syncing QSOs you've logged, not looking up other stations). See Awards & Logging for how that works, including optional automatic downloads.

Updates

Press F4 any time to check for a newer Jimmy Next release in your browser. To have Jimmy Next check on its own, enable Check for updates on startup (General tab, off by default). If a newer version is published, Jimmy Next asks whether to download and install it — say yes, and it downloads the installer, then closes itself and launches it for you. Jimmy Next only ever offers Jimmy Next updates — it never checks against or installs a production Jimmy release, and production Jimmy never checks against Jimmy Next's releases.
