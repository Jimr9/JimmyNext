Get Started

Jimmy Next is self-contained — there's no companion program to track down first. Install it and it's ready to operate.

What you'll need

  • Windows 10 or 11, 64-bit.
  • Nothing else. Jimmy Next bundles a built-in FT8/FT4 engine (based on the free, open-source Nexus project — see Credits) and its own .NET runtime — no separate WSJT-X install, no modified WSJT-X build, no .NET download.

Setup steps

  1. Download the latest Jimmy Next installer (see the Download button on the home page) — it comes as a zip; extract JimmyNext.msi from it and run that. If Jimmy Next is already installed and running, close it first — the installer can't update Jimmy Next while it's open.
  2. Run through the installer, choosing your install location and shortcut preferences (Desktop and Start Menu shortcuts are offered, both on by default).
  3. Start Jimmy Next. It launches its bundled engine automatically in the background — there's no separate program to start first or connect to.

The very first time Jimmy Next runs its bundled engine, Windows Defender (or another antivirus) may take a few extra seconds to scan it — that's expected for a new, unsigned executable and only happens once. If anything looks stuck longer than that, see Troubleshooting.

First run: initial configuration

Jimmy Next doesn't know anything about your station until you tell it. The first time you open Options (Alt+O), set up your callsign, grid square, audio devices, and radio connection — then the Basic tab walks you through the handful of operating choices that matter most:

  • Call CQ mode, or Listen for calls mode.
  • When calling CQ: plain CQ, CQ DX, or both.
  • Whether to also reply to DX stations and stations on your own continent.
  • Parks on the Air role, if relevant: Activator or Hunter.
  • Reply order: in the order calls were received, or most-recent-first.

Radio connection (for CAT control and PTT/audio) is set up from the Radio tab — see Settings. A quick sanity check before your first real transmit: confirm your antenna or a dummy load is connected and your power level is where you expect it, the same way you would before using any new radio program. Everything chosen here can be revisited any time from the same tab, or fine-tuned further on the other Options tabs.

While operating

Once you're running, keep Jimmy Next's own window active and focused — it's designed to be operated entirely from its own window. See Using Jimmy Next for how a typical operating session works, and Keyboard Commands for the full shortcut list.
