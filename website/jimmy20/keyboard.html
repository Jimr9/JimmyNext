Keyboard Commands

Every command below is reachable without a mouse. These are Jimmy Next's defaults — every one of them (except the handful marked fixed) can be reassigned from Options > Hotkeys (Alt+O).

Command keys
KeyAction
Alt+IOpen the row order editor — choose which fields appear in each station row (callsign, reply status, signal report, audio frequency, distance and direction, and more) and in what order, for the Stations calling list, the raw decodes list, and the Spot Watch list.
Alt+OReview or change Options.
Alt+CStart the selected CQ mode (CQ only / CQ DX only / CQ and CQ DX). Does nothing in Listen mode.
Alt+LSelect Listen for calls mode.
Alt+EEnable transmit, or re-enable a timed-out QSO.
Alt+HHalt transmit immediately.
Alt+NSkip to the next available station — very useful.
Alt+JEnter a callsign manually to call.
unassigned by defaultAnalyze transmit slot (find the quietest audio frequency for CQ; requires the Transmit tab's Transmit frequency set to "Best free frequency").
unassigned by defaultLook up the focused station, in any list — Stations calling, TX1/TX2, Raw decodes, or Auto-logged calls (callsign, country, state, LoTW status, and more). Checks QRZ live automatically if that callsign isn't already known.
unassigned by defaultOpen the Ham Radio Center logbook.
unassigned by defaultAdd a manually-logged QSO — jumps straight to the Add New QSO dialog on the Edit Log tab.
Radio configuration keys
KeyAction
Alt+TToggle Tune mode, to set the correct audio output level to your radio.
F12Increase audio output level to the radio (during tune or transmit).
F11Decrease audio output level to the radio (during tune or transmit).
Alt+QQuick check of output power and SWR (during transmit) or audio input (during receive).
Alt+Page UpSelect the next higher band.
Alt+Page DownSelect the next lower band.
Transmit frequency keys
KeyAction
Alt+VAnnounce the current receive and transmit audio frequencies, and which transmit-frequency mode is active.
Shift+F12Move the transmit audio frequency up one step (step is set on the Transmit tab, default 60 Hz).
Shift+F11Move the transmit audio frequency down one step.
Ctrl+Shift+F12Move the receive audio frequency up one step.
Ctrl+Shift+F11Move the receive audio frequency down one step.
Ctrl+F12Set the transmit frequency to the current receive frequency (Tx ← Rx).
Ctrl+F11Set the receive frequency to the current transmit frequency (Rx ← Tx).
Alt+WSet the transmit audio frequency to an exact value — type it in.

These pair with F11/F12 already being audio level down/up: F12 is the up / transmit-side key, F11 the down / receive-side key. No arrow keys are used, so nothing collides with screen-reader navigation. Using any of the transmit keys above during a contact switches that contact to a manual transmit frequency, so Jimmy Next won't automatically pick a different one until you Halt, finish the QSO, change band or mode, or reselect "Best free frequency" in Options. See Using Jimmy Next for the full picture.

Direct band selection

Jimmy Next also has a command for jumping straight to each amateur band (160m through 6m). None of these have a default key — assign your own from Options > Hotkeys if you'd like one-key band changes.

Making a key your own

Open Options > Hotkeys, select any action from the list, and press your preferred key combination to capture it. Jimmy Next validates the new binding on the spot — it must include a modifier key (or be a function key on its own), can't collide with an existing shortcut, and can't use a small set of combinations Windows itself reserves. A "Reset All to Defaults" button is always available if you want to start over.
